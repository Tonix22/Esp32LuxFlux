# Portable synchronization core

Pure C++ RGB models, strict legacy text parser, bounded stream line reader,
sequence store and client/server handshake. No ESP-IDF or LED-backend headers
are included. Host tests live in `tests/sync_core_test.cpp`.

For the full configuration, TCP, parsing, and LED playback path, see
[How a light sequence reaches the LEDs](../../docs/SEQUENCE_CODE_WALKTHROUGH.md).
